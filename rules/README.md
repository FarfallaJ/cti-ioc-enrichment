# Detection Rule Library

Starter detections generated by `ioc_enrich.detect` from indicators assessed in
this portfolio's threat work. Rules are **experimental** — validate and tune
against your own telemetry before production deployment.

## Layout

- `kv-botnet/` — detections for the KV-botnet / Volt Typhoon node `193.36.119.48`
  (Sigma + Suricata).

## Generating more

```bash
python -m ioc_enrich.detect <ioc> [<ioc>...] \
    --context "Campaign name" --out rules/<campaign>/
```

Each IOC is routed to the right format automatically: IPs/domains/URLs →
Sigma + Suricata; file hashes → Sigma + YARA.

## Formats

| Format | Purpose | Deploy to |
|---|---|---|
| Sigma | Log-based detection (SIEM-agnostic) | Splunk, Sentinel, Elastic via sigmac/pySigma |
| Suricata | Network IDS/IPS | Suricata, Snort-compatible engines |
| YARA | File/memory hash matching | EDR, sandbox, IR triage |
